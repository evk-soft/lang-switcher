# lang-switcher

[English](README.en.md)

Лёгкий индикатор текущей раскладки клавиатуры: небольшой бейдж возле курсора мыши и
опциональный звуковой сигнал при переключении — чтобы всегда было видно, на каком языке
вы сейчас печатаете.

**Статус: alpha.** Работает только на Windows 11 x64. Приложение показывает язык ввода,
но не переключает раскладку — этим по-прежнему управляет Windows.

## Скачать

[Последний выпуск](https://github.com/evk-soft/lang-switcher/releases/latest) —
установщик, portable-архив и контрольные суммы.

Установка не требует прав администратора. Файлы **не подписаны сертификатом**, поэтому
Windows покажет предупреждение SmartScreen; перед запуском сверьте SHA-256. Подробно —
[руководство по установке](docs/guide/installation.ru.md).

## Возможности

- Бейдж текущего языка у курсора: на ~1,5 секунды при смене раскладки либо постоянно.
  Поверх всех окон, прозрачен для кликов, не крадёт фокус, корректен на мониторах с разным
  DPI.
- Различимые звуки для русского и английского, нейтральный для остальных языков.
- Меню в трее: режим следования, резервная проверка раскладки, звук, автозапуск, язык
  интерфейса, состояние, выход.
- Интерфейс на шести языках: English, Русский, Deutsch, Español, Français, 简体中文.
  Режим «Как в системе» берёт язык интерфейса Windows.
- Отказ любой части ОС ограничивает одну возможность, а не роняет приложение; причина
  видна в меню «Состояние».
- Ни одного сетевого соединения: ни телеметрии, ни проверки обновлений.

## Ограничения alpha

- Только Windows 11 x64; macOS и Linux не поставляются.
- Файлы не подписаны.
- Режимы IME не проверялись; региональные варианты одного языка получают одинаковую метку.
- Якорь по текстовой каретке не реализован (M2).
- Целевой объём памяти 5–15 МБ не достигнут: измеренный RSS — 17–21 МиБ.

Полный список — в [CHANGELOG](CHANGELOG.md).

## Технология

Чистый нативный **Rust** без webview: Cargo workspace с UI-независимым ядром и адаптерами
под каждую ОС. Обоснование — [аудит технологий](docs/research/2026-07-03-tech-audit.md) и
[ADR-0001](docs/architecture/adr/0001-pure-native-rust.md).

| Крейт | Роль |
| --- | --- |
| `switcher-core` | домен: автомат раскладки, выбор якоря, модель конфига. Без OS-зависимостей, `#![forbid(unsafe_code)]` |
| `switcher-platform` | порты (traits) и плоские типы событий |
| `switcher-windows` | адаптеры Win32/COM — единственное место, где разрешён `unsafe` |
| `switcher-app` | оболочка: трей, главный цикл, растеризация бейджа, локализация, звук, wiring |

[руководстве разработчика](docs/guide/development.ru.md).
