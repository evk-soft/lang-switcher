## Вывод

Назначение понятно: резидентный индикатор текущей раскладки RU/EN возле курсора,
со звуком, треем и автозапуском; Windows 11 сначала. Разделение на независимое ядро,
порты и нативные адаптеры пригодно для продолжения, переписывать проект целиком оснований нет.
На начало аудита были выполнены задачи 1–10 из 21, основной бинарник только проверял
DPI-awareness. После продолжения реализованы задачи 11–20 и резидентный запуск.
M1 всё ещё требует ручной приёмки: проверка ядра не заменяет проверку приложения в работе.

## Исправления плана дальнейшей работы

- TSF: `RPC_E_CHANGED_MODE` нельзя считать успешным созданием STA. `CoUninitialize`
  вызывается только за успешный `CoInitializeEx`, включая `S_FALSE`, после освобождения
  интерфейсов на том же потоке. Уточнено по
  [Microsoft CoInitializeEx](https://learn.microsoft.com/en-us/windows/win32/api/combaseapi/nf-combaseapi-coinitializeex).
- Рантайм: проверять абсолютный дедлайн скрытия перед каждым `select!`, чтобы
  непрерывный поток движений мыши не откладывал скрытие навсегда.
- Запуск: начальное чтение и эффекты `Initial` выполняются до обработки очереди хуков;
  не ставить Initial в хвост уже работающих источников.
- Выход: нужен отдельный сигнал остановки; копии `Sender` у адаптеров не позволяют
  считать канал закрытым после удаления только main-копии. Добавлен сценарий приёмки.
- Автозапуск: после отказа записи перечитать реестр, который мог измениться извне;
  при отказе чтения показывать неизвестное состояние, не выдавая старый конфиг за факт ОС.
- Добавлены требования к регрессионным тестам этих сценариев в задаче 19. Старые
  листинги задачи 5 с ошибочной временной эвристикой удалены.

Обновление геометрии при системных настройках соответствует
[WM_SETTINGCHANGE](https://learn.microsoft.com/en-us/windows/win32/winmsg/wm-settingchange).
Проверялись также контракты
[UpdateLayeredWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-updatelayeredwindow)
и [PostThreadMessageW](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-postthreadmessagew).

- `cargo fmt --all -- --check` — exit 0.
- `cargo clippy --workspace --all-targets --locked -- -D warnings` — exit 0, предупреждений нет.
- `cargo test --workspace --locked` — **87 passed, 0 failed**: core 57, platform 3,
  Windows 26, smoke-пример 1. Doc-tests также завершились успешно.
- Для исправлений сначала наблюдались падения регрессионных тестов, затем успешные прогоны.
- `cargo build --workspace --locked` — exit 0.
- `cargo +1.87.0 check --workspace --all-targets --locked` до и после исправлений — exit 0;
  проверка установленного MSRV потребовала запуска вне песочницы из-за Access is denied.
- `RUST_LOG=debug cargo run -p switcher-app --locked` — exit 0,
  `from_manifest=true per_monitor_v2=true`. Это проверка манифеста, не рабочего приложения.

При проверке обработчика ошибок реально воспроизведён отказ из-за неверного буфера;
отказ GDI/UpdateLayeredWindow не инъецировался. Для него проверен код общего пути очистки.
Тест `WM_SETTINGCHANGE` проверяет реакцию обработчика, не меняет настройки пользователя.

Ручные click-through, отсутствие кражи фокуса, topmost, изменение панели задач,
визуальный mixed-DPI и NFR готового приложения повторно **не проверялись**.
Linux/macOS и удалённый CI в этом аудите не запускались. Ранее записанные ручные
наблюдения 2026-08-25 сохранены отдельно в [чеклисте](../smoke/m1-windows.md).

## Продолжение

Задачи 11–20 реализованы последовательно в основной папке, ветка `feat/m1-windows-mvp`.
Независимые агенты выполняли только ревью. Найденные при продолжении дефекты закрыты:

| Область | Исправление и доказательство |
|---|---|
| Windows-источники | Прерываемые pump/backoff, очистка старого WM_QUIT перед перезапуском, восстановление после отказа wake и остановка публикации при отказе KillTimer; native-регрессии |
| TSF | Баланс COM S_OK/S_FALSE, явный отказ RPC_E_CHANGED_MODE, sink без IAgileObject, отписка на STA; unit/native-тесты |
| Трей | Нативно подтверждён straight-RGBA для CreateIcon; premultiplied вход затемнял полупрозрачные пиксели. Длинная метка больше не меняет заявленные размеры иконки |
| Рантайм | Абсолютный дедлайн не голодает при непрерывном Raw Input; устаревшая координата не переносит новый бейдж назад; скрытый бейдж не воскресает от DPI/Ok |
| Деградация | Отказ оверлея снимает трекинг, восстановление перепроверяет DPI; отказ звука сохраняет предпочтение; отказ автозапуска перечитывает реестр и синхронизирует галку |
| Конфиг | Сохранение через временный файл в том же каталоге; повреждённый/более новый TOML защищён от перезаписи; native roundtrip |
| Запуск и выход | Начальный снимок до очереди источников; fallible setup до core spawn; stop/ack/join после ошибки трея; отдельное сообщение окну завершает модальный цикл (ADR-0015) |
| Первый лог | Каталог создаётся до retention scan; свежий release-запуск имеет пустой stderr |
