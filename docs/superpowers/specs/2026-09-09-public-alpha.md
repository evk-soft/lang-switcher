# Спецификация: первая публичная alpha (v0.1.0-alpha.1)

Дата: 2026-09-09. Статус: принята владельцем проекта.

Исследование: [локализация и распространение](../../research/2026-09-09-alpha-localization.ru.md)
([English](../../research/2026-09-09-alpha-localization.en.md)).

## Цель

Выпустить первую публично скачиваемую версию lang-switcher: открытый репозиторий,
GitHub prerelease `v0.1.0-alpha.1` с установщиком для Windows, portable-архивом и
контрольными суммами; мультиязычный интерфейс и двуязычная пользовательская
документация.

Alpha не означает завершённый M1. Ограничения перечисляются явно (см. «Ограничения»).

## Объём

### 1. Гигиена зависимостей

- MSRV 1.87 → **1.88** в `Cargo.toml`, CI-джобе, README и docs.
- `time` 0.3.45 → ≥ 0.3.47 (закрывает RUSTSEC-2026-0009 через `tracing-appender`).
- `ttf-parser` 0.25.1 (RUSTSEC-2026-0192, объявление о прекращении поддержки, не CVE):
  принятый долг alpha. Обоснование: разбирается только встроенный доверенный субсет
  Inter, шрифты из недоверенных источников не загружаются. Зафиксировать в `SECURITY.md`.

### 2. Локализация интерфейса

**Формат.** Fluent (`fluent-bundle` + `unic-langid`), каталоги `.ftl` встраиваются
в бинарник через `include_str!`. Сеть для переводов не используется.

**Локали alpha.** `en` (базовая и резервная), `ru`, `de`, `es`, `fr`, `zh-Hans`.

**Настройка.** `ui_language` в конфиге принимает:

- `"auto"` — язык интерфейса Windows (значение по умолчанию для новых установок);
- канонический языковой тег, например `"ru"`, `"zh-Hans"`.

Значение нормализуется (`EN` → `en`, `zh-hans` → `zh-Hans`); неразбираемое значение
сбрасывается в `auto` с предупреждением. Ранее сохранённые явные `ru`/`en` продолжают
работать без изменений — они уже канонические.

Подбор локали: запрошенный тег → тот же язык с другим регионом/письменностью →
`en`. Отсутствующее сообщение в выбранном каталоге берётся из `en`.

**Источник системного языка.** Порт `switcher-platform::ports::UiLanguages` с методом
`preferred() -> Vec<String>`. Windows-адаптер вызывает `GetUserPreferredUILanguages`
(язык интерфейса, а не раскладка `GetKeyboardLayout` и не региональные форматы).
Через границу порта проходят только обычные строки.

**Трей.** Подменю «Язык / Language» с пунктами-переключателями: «Как в системе» и
названия языков на них самих (English, Русский, Deutsch, Español, Français, 简体中文).
Выбор применяется немедленно: перерисовываются подписи меню, подсказка и строки
состояния; настройка сохраняется. Смена языка интерфейса **не** воспроизводит звук
смены раскладки и не показывает бейдж.

**Что не переводится.** Стабильные машинные ключи (`Capability::key()`), коды ошибок
адаптеров, поля логов, значения конфига. Переводится только то, что видит пользователь.

**Тесты.** Синтаксис каждого каталога; полнота набора идентификаторов относительно `en`;
отсутствие дубликатов; совместимость аргументов; подбор локали; резерв на `en`;
сохранение и восстановление настройки; неизменность диагностических кодов.

### 3. Метка бейджа

`BadgeContent::for_lang` сохраняет весь основной языковой субтег вместо первых двух
символов: `fil` → `FIL`, а не `FI`. Двухбуквенные коды не меняются. Растеризатор уже
подбирает ширину по чернилам глифов, поэтому трёхбуквенная метка помещается и в бейдж,
и в иконку трея.

Автоматическое переключение раскладок не добавляется: продукт — индикатор.

### 4. Установщик и артефакты

- **Inno Setup**, `PrivilegesRequired=lowest`, установка в каталог текущего
  пользователя, ярлык в меню «Пуск», штатное удаление.
- `AppMutex`/`SetupMutex` — именованный mutex работающего приложения, чтобы установка,
  обновление и удаление не шли поверх запущенной копии.
- Одиночный экземпляр обычного запуска (тот же mutex). Диагностические запуски с
  `--data-dir` исключены из проверки.
- Конфиг и логи сохраняются при обновлении; удаление убирает файлы приложения и его
  запись автозапуска, не трогая чужие значения реестра. Пользовательские данные
  по умолчанию остаются.
- Артефакты выпуска: установщик `.exe`, portable `.zip`, `SHA256SUMS.txt`,
  `THIRD-PARTY-LICENSES.md`, release notes ru/en.
- Сборка: `x86_64-pc-windows-msvc`, release-профиль, ресурс версии и манифест.

### 5. Документация

`README.md` (ru) + `README.en.md`, и парные файлы в `docs/guide/`:

| Документ | Содержание |
|---|---|
| `installation` | установка, обновление, удаление, portable, SmartScreen, контрольные суммы |
| `settings` | меню трея, все поля `config.toml`, пути к конфигу и логам |
| `development` | сборка, гейты, структура workspace, ручные проверки |
| `translations` | как добавить новый язык интерфейса и как добавить язык документации |

`CHANGELOG.md` — общий, записи на двух языках. `SECURITY.md` — на английском.

### 6. Публикация

1. Проверки: fmt, clippy, тесты, MSRV, сборка установщика, установка/запуск/удаление.
2. PR из `feat/m1-windows-mvp` в `main`; PR #1–#4 закрываются со ссылкой на него.
3. Draft prerelease с артефактами → проверка скачивания → публикация.
4. Видимость репозитория меняется на публичную.

## Ограничения alpha (объявляются в release notes и README)

- Только Windows 11 x64. macOS и Linux не поставляются; Linux CI проверяет
  переносимость ядра, а не готовое приложение.
- Артефакты не подписаны: SmartScreen покажет предупреждение. Контрольные суммы
  публикуются для проверки.
- Приложение показывает язык ввода; переключением раскладки управляет Windows.
- Режимы IME (например, прямой ввод и хирагана) не проверялись. Региональные варианты
  одного языка получают одинаковую метку.
- Якорь-каретка не реализован (M2): бейдж привязан к курсору или фиксированному углу.
- Не проверены: Windows Terminal после исправления аудио, полный набор классов окон и
  повышение привилегий, mixed-DPI, реальный автозапуск после установки,
  целевой объём памяти 5–15 МБ (измеренный RSS 17–21 МиБ).
- `ttf-parser` 0.25.1 объявлен неподдерживаемым (RUSTSEC-2026-0192); принятый долг.
