# 0001. Стек — чистый нативный Rust, без webview

Дата: 2026-07-03. Статус: accepted.

## Контекст

Приложение — постоянно резидентная утилита-индикатор раскладки. Ключевые нефункциональные требования: ~0% CPU в простое, минимальная RAM, мгновенный старт при автозапуске, click-through оверлей у курсора. [Аудит июня 2026](../../research/2026-07-03-tech-audit.md) показал: сложная часть (события раскладки, каретка, оверлей) — рукописный нативный код в любом стеке; фреймворки дают только «оболочку» ценой 50–250 МБ RAM.

## Решение

Чистый Rust без webview/JVM/Chromium: платформенные хуки на windows-rs / objc2 / x11rb + zbus, оверлей на сырых платформенных окнах, трей на крейтах tray-icon + muda (те же, что использует Tauri), звук через rodio, окно настроек — egui, создаваемое по требованию и полностью уничтожаемое при закрытии. Целевой footprint: бинарник 1–4 МБ, ~5–15 МБ RSS в простое.

## Рассмотренные альтернативы

- **Tauri 2.11** — второе место двух линз аудита; экономит только тривиальную оболочку, RAM-пол ~50–80 МБ, открытые баги прозрачных окон на macOS, риск джиттера webview-окна при следовании за курсором.
- **Avalonia 12 + .NET 10** — достойный вариант «один язык на всё», но 40–100 МБ RAM и Skia-swapchain на окно; click-through всё равно рукописный P/Invoke.
- **Electron 43** — максимальная скорость разработки, но 150–250 МБ RAM структурно нарушает смысл продукта.
- **Flutter 3.44** — multi-window не в stable, прозрачность на Windows — workaround с 2020 г.
- **Compose 1.11** — JVM-прогрев при автозапуске, 108–146 МБ RSS, desktop вторичен для JetBrains.

## Последствия

- (+) Footprint соответствует позиционированию продукта; это часть его маркетинга.
- (+) Нативные хуки живут в том же процессе без FFI-мостов; Tauri-оболочку можно прикрутить позже без переписывания ядра (ядро UI-независимо, ADR-0002).
- (−) Мы владеем всей оболочкой сами: три платформенных стека без страховки фреймворка; порты macOS/Linux — отдельные milestone'ы, не «пересборка».
- (−) UI настроек скромнее HTML-аналогов; принимаем для утилиты этого класса.
- (−) Инсталлятор/обновления собираем сами (cargo-wix / Inno, winget).
