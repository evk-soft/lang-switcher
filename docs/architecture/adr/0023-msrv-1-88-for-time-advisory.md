# 0023. MSRV поднимается до 1.88 ради исправленного `time`

Дата: 2026-09-09. Статус: accepted.

## Контекст

Аудит готовности к публикации ([отчёт](../../research/2026-09-09-alpha-localization.ru.md),
проверка OSV по 101 пакету `Cargo.lock`) нашёл одно применимое предупреждение:

- **RUSTSEC-2026-0009 / GHSA-r6v5-fh4h-64xc** в `time` 0.3.45 — исчерпание стека
  при разборе вредоносной строки RFC 2822. `time` приходит транзитивно через
  `tracing-appender` 0.2.5, который использует его для имён файлов журнала.
  Уязвимого пути в приложении не найдено: формат даты фиксирован, RFC 2822 не
  разбирается. Исправлено в `time` ≥ 0.3.47.
- `time` 0.3.47 требует Rust 1.88, а проект обещал 1.87.

Второе предупреждение, **RUSTSEC-2026-0192** в `ttf-parser` 0.25.1, — объявление
о прекращении поддержки, а не уязвимость.

## Решение

- `workspace.package.rust-version` = **1.88**. Согласованно обновляются джоба
  `msrv` в `.github/workflows/ci.yml`, README (ru/en) и руководство разработчика.
- `time` обновляется до 0.3.55 (первая доступная версия ≥ 0.3.47 на дату решения).
- `ttf-parser` 0.25.1 остаётся: это принятый и записанный долг alpha.
  Обоснование — растеризуется только встроенный субсет Inter, поставляемый
  вместе с бинарником (ADR-0014); шрифты из недоверенных источников не
  загружаются, поэтому недоверенного ввода у парсера нет. Замена всего
  растеризатора ради объявления о поддержке не входит в объём alpha и записана
  в `SECURITY.md`.

## Рассмотренные альтернативы

- Оставить `time` 0.3.45 и сохранить MSRV 1.87: публичный выпуск ушёл бы с
  известным незакрытым advisory в `Cargo.lock`. Отсутствие уязвимого пути — это
  аргумент против срочности, но не повод не обновляться, когда обновление
  доступно и ничего не ломает.
- Убрать `tracing-appender` и написать собственную ротацию журналов: сохранило
  бы 1.87, но заменило бы проверенную библиотеку своим кодом ради версии
  компилятора, которая ничем не обязана пользователям alpha.
- Заменить `ab_glyph`/`ttf-parser` на другой растеризатор: несоразмерно
  объявлению о прекращении поддержки и затронуло бы ADR-0006 и ADR-0014.

## Последствия

Порог входа для сборки из исходников поднимается на одну минорную версию Rust.
Для пользователей выпуска изменений нет: поставляется собранный бинарник.

Появляется обязательство держать проверку OSV перед каждым выпуском и
пересматривать долг по `ttf-parser`, если по нему появится настоящий CVE.
