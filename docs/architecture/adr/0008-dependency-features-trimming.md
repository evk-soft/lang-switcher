# 0008. Зависимости подключаются с `default-features = false`; лишние декодеры, PNG и variable-шрифты выключены

Дата: 2026-08-25. Статус: accepted.

Дополнение 2026-09-08: выбор rodio заменён прямым WASAPI по
[ADR-0016](0016-demand-driven-wasapi-cues.md); tray-icon закреплён с локальным
патчем по [ADR-0017](0017-disable-unused-tray-hover.md). Исходные листинги ниже
сохранены как история; остальные правила урезания фич остаются в силе.

## Контекст

NFR требуют бинарник 1–4 МБ и RSS 5–15 МБ. Каркас (задача 1) подключил зависимости по версии, с default-фичами и без разбора: `rodio`, `tray-icon`, `muda`, `tiny-skia`, `ab_glyph`. Проверка `Cargo.lock` показала, что за default-фичами уже пришло то, чего продукт не использует: `rodio` притащил symphonia (десятки крейтов), `rand`, `rand_distr`, `rtrb` — при том, что M1 не декодирует ни одного файла, а синтезирует два тона; `tiny-skia` притащил `png`, `flate2`, `miniz_oxide`, `fdeflate`, `crc32fast`, `adler2` — при том, что PNG не читается и не пишется.

Дополнительно выяснилось, что `muda` объявлена отдельной зависимостью напрасно: `tray-icon` реэкспортирует её целиком как `tray_icon::menu`, и в графе ровно одна её версия. А `embed-manifest` объявлен в `[workspace.dependencies]`, но не используется никем — его нет ни в `Cargo.lock`, ни в локальном реестре.

## Решение

Каждая зависимость подключается с `default-features = false` и явным списком фич:

```toml
rodio      = { version = "0.22", default-features = false, features = ["playback"] }
tray-icon  = { version = "0.24", default-features = false }
tiny-skia  = { version = "0.12", default-features = false, features = ["std", "simd"] }
ab_glyph   = { version = "0.2",  default-features = false, features = ["std"] }
```

Обоснование по каждой строке (проверено по исходникам в реестре):

- **`rodio` только `playback`** — единственная нужная фича (`playback = ["dep:cpal"]`); сборка без декодеров поддерживается авторами явно (в `DecoderImpl` есть вариант-заглушка «to satisfy the compiler when there are no decoders enabled»). Выключение default выкидывает symphonia, `recording`, `dither`.
- **`tiny-skia`: `std` обязателен** (без него крейт останавливает сборку `compile_error!`), `simd` даёт SSE2-путь на стабильном компиляторе; отсутствие `png-format` убирает семь транзитивных крейтов (`png`, `flate2`, `miniz_oxide`, `fdeflate`, `crc32fast`, `adler2`, `simd-adler32`).
- **`ab_glyph` без `variable-fonts`** корректно ровно потому, что по ADR-0006 встраивается статический инстанс шрифта, а не variable.
- **`tray-icon` без default** — его default-фичи (`libxdo`, `gtk`) целятся только в Linux, а на Windows `platform_impl` вообще не имеет feature-гейтов. На M4 фичи включатся отдельной target-секцией.
- **`muda` удаляется из `[workspace.dependencies]`** — используется как `tray_icon::menu`.
- **`embed-manifest` удаляется из `[workspace.dependencies]`** до момента, когда появится `build.rs`, который его действительно вызовет; сейчас это объявление, вводящее в заблуждение (чем встраивается манифест — ADR-0010).
- **`switcher-app` приобретает `thiserror`** (для `RenderError` из ADR-0006) и подключает `tray-icon` только под `cfg(windows)` — в M1 трей есть лишь на Windows.
- **`switcher-windows`** получает только те фичи `windows`, которые нужны его модулям, и каждую — в коммите вместе с кодом, который её требует. Ожидаемый набор M1: `Win32_Foundation`, `Win32_UI_WindowsAndMessaging` (каркас), `Win32_Graphics_Gdi`, `Win32_UI_HiDpi`, `Win32_System_Threading`, `Win32_System_LibraryLoader` (фундамент и оверлей — ADR-0005), `Win32_UI_Input`, `Win32_UI_Accessibility`, `Win32_UI_Input_KeyboardAndMouse`, `Win32_Globalization`, `Win32_Storage_Packaging_Appx` (источники раскладки и курсор — ADR-0007), `Win32_System_Com` + `Win32_UI_TextServices` (TSF), `Win32_System_Registry` (автозапуск). Список **не** объявляется закрытым: источник истины — карта фич в задаче 8 плана, где у каждой строки назван потребитель и задача.

Правило на будущее: **фича добавляется в тот же коммит, что и код, который её требует**, и никогда «на будущее». Соблюдение проверяется тем, что сборка падает без неё.

## Рассмотренные альтернативы

- **Оставить default-фичи, разбираться при упаковке.** Отклонено: бюджет бинарника — NFR, а не пожелание; чем позже режешь граф, тем дороже (symphonia уже влияет на время сборки и на CI).
- **Держать `muda` отдельной зависимостью «для явности».** Отклонено: два пути к одному типу — источник несовпадения версий; реэкспорт гарантирует единственную версию.
- **Оставить `embed-manifest` объявленным заранее.** Отклонено: объявление, которое никто не использует, читается как «уже подключено» — именно этой ошибкой был испорчен предыдущий план.
- **Взять предзаписанные WAV/OGG-сэмплы вместо синтеза.** Отклонено для M1: вернуло бы декодеры (symphonia и его окружение) в граф ради двух коротких тонов. Решение фиксируется здесь же; реализация синтеза — задача 16 плана.
- **Указать `panic = "abort"` в release для уменьшения бинарника.** Отклонено жёстко: unwind — необходимое условие работы супервизора потоков хуков (ADR-0007).

## Последствия

- Урезание фич обязано быть проверено сборкой в той же задаче: конфигурация `rodio` без декодеров логична по исходникам, но фактом является только зелёный `cargo check`. То же для `tiny-skia`/`ab_glyph` без default.
- `switcher-app` перестаёт собираться под non-Windows, как только `tray-icon` уходит под `cfg(windows)`: модуль трея закрывается `#[cfg(windows)]`. Гарантия «ядро собирается на любой ОС» этим не затрагивается — она про `switcher-core` и `switcher-platform`, и именно это проверяет отдельный джоб CI.
- Появляется обязательство собрать файл сторонних лицензий при упаковке (M2): BSD-3-Clause у `tiny-skia`, Apache-2.0 у `ab_glyph`, лицензия встроенного шрифта, лицензии `windows`/`tray-icon`/`rodio`.
- Замер «бинарник в бюджете 1–4 МБ» становится проверяемым пунктом smoke-чеклиста M1, а не надеждой.
