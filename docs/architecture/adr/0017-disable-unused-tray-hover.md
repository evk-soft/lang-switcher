# 0017. Неиспользуемое отслеживание наведения в трее отключается при создании

Дата: 2026-09-08. Статус: accepted.

## Контекст

tray-icon 0.24.1 создаёт 15-мс таймер для событий Move/Leave. Обработчик забирает
last_position через take(), но оставляет таймер, если курсор ещё внутри значка.
После этого таймер может работать бессрочно. Приложение не использует Enter,
Move и Leave; постоянный опрос нарушает ADR-0003 даже без этого дефекта.
Публичной настройки для отключения hover в этой версии нет.

## Решение

Закрепить tray-icon =0.24.1 и небольшой локальный патч через [patch.crates-io].
Исходники, лицензии и сведения о происхождении хранятся в vendor/tray-icon.
Добавить Windows-only параметр создания hover_tracking, по умолчанию true,
и builder with_hover_tracking. Приложение передаёт false. Windows-обработчик
возвращается до GetCursorPos, Shell_NotifyIconGetRect и SetTimer для WM_MOUSEMOVE.
Обработка кликов, меню, tooltip и TaskbarCreated сохраняется.

Это отключает ненужный механизм в приложении. Исходный режим hover=true
не изменяется и сохраняет известный дефект; патч не объявляется общим исправлением
hover-библиотеки. При обновлении зависимости нужно повторно проверить native smoke.

## Альтернативы

- Убивать таймер по его private ID из приложения: хрупкая зависимость от внутренних
  сообщений и владения HWND, вмешательство после каждого наведения.
- Переписать трей: несоразмерно узкому дефекту, усложнит меню и восстановление Explorer.
- Исправить только take(): постоянный таймер при наведении всё равно не нужен M1.

## Проверка и последствия

Native smoke создаёт временные значки, посылает сообщения только собственному HWND
и считает фактические WM_TIMER. Контроль с hover=true должен дать события и таймер;
hover=false — ни одного. Оба режима должны доставлять клики. Курсор и фокус
пользователя тест не меняет. Unsafe теста находится только в switcher-windows.

Контракты сверены с Microsoft:
[SetTimer](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-settimer),
[KillTimer](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-killtimer),
[SendMessageW](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendmessagew).
После патча повторяются release CPU/RSS и полные гейты.
