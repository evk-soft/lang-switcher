# ADR-0014: встроенный статический Inter SemiBold

- Статус: принято
- Дата: 2026-09-07

## Контекст

Растеризатор ADR-0006 требует доступного без файлового ввода шрифта и одного веса.
Зависеть от установленного в Windows шрифта нельзя: геометрия менялась бы между машинами.

## Решение

Включить через `include_bytes!` статический Inter SemiBold из официального релиза v4.1
(внутренняя версия 4.001), сокращённый fonttools 4.64.0 до `A–Z`, `0–9`, `?`.
[Лицензия SIL OFL 1.1](../../../crates/switcher-app/assets/fonts/LICENSE.txt) прочитана
из архива и включена без изменений. [Источник и воспроизведение](../../../crates/switcher-app/assets/fonts/README.md).
В заголовке лицензии нет Reserved Font Name. Изменение представляет собой сабсет.

Размер артефакта 15 304 байта; таблицы variable font отсутствуют. Дополнительные
фичи ab_glyph и декодеры изображений не нужны. Метки ядра обычно ASCII, однако
неизвестная Unicode-метка допустима: любой отсутствующий глиф переводит бейдж
в непустой цветной квадрат, без частично отображённых букв.

## Последствия

Шрифт и метрики неизменны в течение жизни кэша. Кэш ограничен 16 элементами и
включает в ключ всё содержимое и DPI. Результат — premultiplied BGRA.
Растеризатор находится в библиотечной части switcher-app для unit-тестов,
runtime и примеров, не требующих запуска резидентного приложения.

При упаковке M2 собрать сторонние лицензии: OFL шрифта, BSD-3-Clause tiny-skia,
Apache-2.0 ab_glyph. Добавление алфавитов требует пересоздания сабсета и обновления
его контрольной суммы. Визуальные метрики требуют проверки на 100/150/200%.
