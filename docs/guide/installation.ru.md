# Установка

[English](installation.en.md) · [Настройки](settings.ru.md) · [Переводы](translations.ru.md)

## Что нужно

- Windows 11 x64 (сборка 22000 или новее).
- Права администратора **не нужны**: приложение ставится в профиль текущего пользователя.

Windows 10 не проверялась. Установщик её не запустит: в нём указано минимальное
требование 10.0.22000.

## Скачивание

Файлы выпуска — на странице
[Releases](https://github.com/evk-soft/lang-switcher/releases).

| Файл | Что это |
| --- | --- |
| `lang-switcher-<версия>-windows-x64-setup.exe` | установщик |
| `lang-switcher-<версия>-windows-x64-portable.zip` | версия без установки |
| `SHA256SUMS.txt` | контрольные суммы обоих файлов |

## Предупреждение SmartScreen

Файлы alpha **не подписаны сертификатом**: подписи у проекта пока нет. Windows покажет
синее окно «Система Windows защитила ваш компьютер». Чтобы продолжить, нажмите
«Подробнее» → «Выполнить в любом случае».

Прежде чем это делать, сверьте контрольную сумму. Она — единственная проверка
целостности, которая есть у неподписанного файла:

```powershell
Get-FileHash .\lang-switcher-0.1.0-alpha.1-windows-x64-setup.exe -Algorithm SHA256
```

Полученное значение должно совпадать со строкой для этого файла в `SHA256SUMS.txt`
(регистр букв не важен). Если не совпадает — не запускайте файл.

## Установка

Запустите `...-setup.exe` и пройдите мастер. Установщик:

- ставит приложение в `%LOCALAPPDATA%\Programs\lang-switcher`;
- создаёт ярлык в меню «Пуск»;
- регистрирует запись для удаления в «Приложения и возможности»;
- предлагает запустить приложение по завершении.

Мастер доступен на английском, русском, немецком, испанском и французском.

Автозапуск при входе в систему установщик **не** включает: это галка в меню трея
(см. [настройки](settings.ru.md)).

### Тихая установка

```powershell
.\lang-switcher-0.1.0-alpha.1-windows-x64-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```

## Портативная версия

Распакуйте архив в любой каталог и запустите `lang-switcher.exe`. Настройки и логи всё
равно хранятся в `%APPDATA%` и `%LOCALAPPDATA%` — так же, как у установленной копии.

Важное отличие: автозапуск сохраняет **абсолютный путь** к тому файлу, из которого вы
включили галку. Если после этого перенести каталог, запись автозапуска будет указывать
на старое место. Снимите и заново поставьте галку после переноса.

## Обновление

Запустите установщик новой версии поверх старой. `AppId` тот же, поэтому новая версия
заменяет прежнюю, а не появляется рядом с ней. Настройки и логи сохраняются.

Если приложение запущено, установщик попросит его закрыть — он определяет работающую
копию по именованному mutex.

## Удаление

«Параметры» → «Приложения» → «Установленные приложения» → lang-switcher → «Удалить».

Удаление убирает файлы приложения, ярлык и запись автозапуска в реестре, если она была
создана.

**Настройки и логи остаются намеренно** — это ваши данные. Чтобы стереть и их:

```powershell
Remove-Item "$env:APPDATA\evk-soft\lang-switcher" -Recurse
Remove-Item "$env:LOCALAPPDATA\evk-soft\lang-switcher" -Recurse
```

## Где что лежит

| Что | Путь |
| --- | --- |
| Программа | `%LOCALAPPDATA%\Programs\lang-switcher` |
| Настройки | `%APPDATA%\evk-soft\lang-switcher\config\config.toml` |
| Логи | `%LOCALAPPDATA%\evk-soft\lang-switcher\data\logs` |
| Автозапуск | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, значение `lang-switcher` |

## Если что-то не работает

- **Приложение не запускается второй раз.** Так и задумано: одновременно работает одна
  копия на сеанс. Значок уже есть в трее — возможно, он скрыт за стрелкой «Показать
  скрытые значки».
- **Бейдж не появляется при смене языка.** Проверьте, что включена «Резервная проверка
  раскладки» в меню трея. Некоторые окна не отправляют Windows уведомление о смене языка,
  и без резервной проверки смена останется незамеченной.
- **Что-то работает не полностью.** Меню трея → «Состояние». Строки там — диагностика:
  они не переводятся и предназначены для отчёта об ошибке. Приложите их вместе с логом
  за нужный день.
