# Настройки

[English](settings.en.md) · [Установка](installation.ru.md) · [Переводы](translations.ru.md)

Всё управление — через меню значка в трее (левый или правый щелчок). Отдельного окна
настроек в этой версии нет; оно относится к M2.

## Меню трея

| Пункт | Что делает |
| --- | --- |
| **Следовать за курсором** | бейдж виден постоянно и следует за курсором мыши, вместо того чтобы появляться на ~1,5 с при смене раскладки |
| **Резервная проверка раскладки** | опрос активного окна каждые 200 мс, когда Windows не присылает уведомление о смене языка |
| **Звук** | короткий сигнал при смене раскладки |
| **Автозапуск** | запуск при входе в систему |
| **Язык** | язык интерфейса самого приложения |
| **Состояние** | диагностика: что работает не полностью |
| **Выход** | завершение работы |

Любое изменение применяется сразу и сохраняется в файл настроек.

### Резервная проверка раскладки

Включена по умолчанию. Некоторые окна не отправляют Windows уведомление о смене языка
ввода — без резервной проверки бейдж в них не обновится до следующего события.

Снятая галка полностью убирает таймер: приложение остаётся полностью событийным, но в
таких окнах смена языка может остаться незамеченной. Подробности и замеры —
[ADR-0019](../architecture/adr/0019-configurable-layout-fallback.md).

### Язык

Подменю «Язык» содержит «Как в системе» и названия языков на них самих: English,
Русский, Deutsch, Español, Français, 简体中文.

Это язык **интерфейса приложения**. Он никак не связан с языком, на котором вы печатаете:
раскладками управляет Windows, а приложение их только показывает.

«Как в системе» берёт язык интерфейса Windows
(`GetUserPreferredUILanguages`) — не раскладку и не региональные форматы дат. Если для
этого языка перевода нет, интерфейс будет английским.

Смена языка перерисовывает меню, подсказку и состояние сразу. Звук при этом не
воспроизводится и бейдж не показывается: выбор языка меню — не событие ввода.

### Состояние

Показывает «Всё работает» либо список ограничений. Строки ограничений выглядят так:

```
sound: device_open_failed — No audio endpoint available
```

Они **намеренно не переводятся**: это ключ возможности, стабильный код ошибки и
техническое описание от адаптера. Именно их нужно прикладывать к отчёту об ошибке — в
любом языке интерфейса они одинаковы и совпадают с содержимым лога.

## Файл настроек

`%APPDATA%\evk-soft\lang-switcher\config\config.toml`

Файл создаётся при первом сохранении настройки, а не при первом запуске. Его можно
править вручную при закрытом приложении.

```toml
version = 1
autostart = false
log_level = "info"
ui_language = "auto"

[badge]
mode = "transient"
anchor = "auto"
style = "text"
show_ms = 1500

[badge.colors]

[sound]
enabled = true
volume = 0.4

[layout]
fallback_enabled = true
```

| Поле | Значения | По умолчанию | Смысл |
| --- | --- | --- | --- |
| `version` | `1` | `1` | версия схемы; более новая не открывается и не перезаписывается |
| `autostart` | `true` / `false` | `false` | зеркало значения в реестре; истина — реестр, а не файл |
| `log_level` | `error` `warn` `info` `debug` `trace` `off` | `info` | уровень записи в лог |
| `ui_language` | `auto` или языковой тег | `auto` | язык интерфейса |
| `badge.mode` | `transient` / `follow` | `transient` | появляется на время или виден постоянно |
| `badge.anchor` | `auto` / `cursor` / `fixed` | `auto` | к чему привязан бейдж |
| `badge.style` | `text` / `color` | `text` | буквы языка или цветной квадрат |
| `badge.show_ms` | 200…10000 | `1500` | сколько миллисекунд виден бейдж в режиме `transient` |
| `badge.colors` | тег → `"#RRGGBB"` | пусто | свой цвет фона для языка |
| `sound.enabled` | `true` / `false` | `true` | звук при смене раскладки |
| `sound.volume` | 0.0…1.0 | `0.4` | громкость сигнала |
| `layout.fallback_enabled` | `true` / `false` | `true` | резервная проверка раскладки |

### Как обрабатываются неверные значения

Приложение не отказывается запускаться из-за плохого файла:

- значение вне диапазона зажимается в границы (`show_ms = 50` → `200`);
- неизвестный `log_level` заменяется на `info`;
- `ui_language`, который не является языковым тегом, заменяется на `auto`;
- цвет не в формате `#RRGGBB` удаляется;
- неизвестные поля игнорируются, поэтому конфиг переживает откат на прежнюю версию.

Каждая правка попадает в лог и в подменю «Состояние».

**Повреждённый или более новый файл не перезаписывается.** Приложение запускается с
настройками по умолчанию, а сохранение отключается на всю сессию, чтобы не уничтожить
файл, который вы, возможно, правили руками.

### Свои цвета бейджа

Ключ — основной языковой субтег. Регион и регистр нормализуются (`ru-RU` и `RU`
приводятся к `ru`):

```toml
[badge.colors]
ru = "#D64545"
en = "#3D6FD9"
de = "#2E8B57"
```

По умолчанию у русского и английского свои цвета, у остальных языков — нейтральный
серый.

## Логи

`%LOCALAPPDATA%\evk-soft\lang-switcher\data\logs`, по файлу на сутки UTC, хранятся
последние семь.

Уровень из файла настроек можно перекрыть переменной окружения — она удобна для разовой
диагностики без правки конфига:

```powershell
$env:LANG_SWITCHER_LOG = "debug"
& "$env:LOCALAPPDATA\Programs\lang-switcher\lang-switcher.exe"
```

## Диагностический запуск

Отдельный экземпляр с собственным каталогом данных, не мешающий обычной копии и не
подпадающий под ограничение «одна копия на сеанс»:

```powershell
& "$env:LOCALAPPDATA\Programs\lang-switcher\lang-switcher.exe" --data-dir C:\temp\ls-diag --run-for 30
```

`--run-for` принимает 1…3600 секунд. Без него приложение работает до выхода через трей.
